## Notes on the big choices

**Why not build our own video?** A dependable video system needs media servers in several regions, network traversal, bandwidth adaptation, recording and around-the-clock operations. That is a company-sized project. LiveKit is open source, so if the platform later reaches a scale where self-hosting is cheaper, we can move without rewriting the app.

**Why LiveKit over Agora?** Agora's network is excellent, and if real-world tests in South African classrooms showed clearly better audio, it would be worth the price. So the Phase 2 trial measures both on real local connections before we commit. At list prices, LiveKit costs about **$500 a month** at the 5,000-learner scenario, against about **$6,000** for Agora ([Costs](10-costs.md)).

**Why stay on Lovable Cloud?** It is already connected, it handles schema changes through Lovable, and it is the cheapest option at pilot size. Before Phase 7 we confirm three things with Lovable: backup and point-in-time-restore options, the storage region, and the path to move to a directly managed Supabase project if usage-based credits become unpredictable at scale.
